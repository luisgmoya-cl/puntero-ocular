Juego: responde sin hablar

Escribe o elige una pregunta, pulsa “Preguntar” y responde moviendo la cabeza: asiente para sí, niega para no.

Aviso honesto: ningún software puede leer pensamientos a través de una cámara. Este programa detecta movimientos de músculos faciales (con el modelo Face Landmarker de MediaPipe) y los traduce a estados probables. Las expresiones no siempre reflejan lo que sientes, así que tómalo como una estimación.
